Nesta revisão: a cultura deixa de ser só acervo e passa a ter dinheiro rastreável. Entram as três portas de financiamento, o FICC no município, o painel da PNAB na União e a consulta de projetos do Fomento CultSP e do ProAC ICMS no estado, mais o Mapa da Cultura, que localiza agentes e espaços por região e serve para achar fonte, não para contar quantos existem. Fora do tema, entra a pesquisa de proposições da Câmara Municipal de Campinas: o guia cobria o Executivo inteiro e ignorava o Legislativo, onde o orçamento é discutido antes de virar lei.

Acesso Programático a Dados (Python e SQL)

Séries econômicas e microdados podem ser puxados de forma reprodutível, com fonte e período documentados automaticamente. 14.1 · Python — ipeadatapy (séries do Ipea, BCB e IBGE)

A biblioteca ipeadatapy lê as séries do IPEA Data, que reúne câmbio, inflação, juros, emprego e renda.

Instalação (uma vez só)

No Prompt de Comando do Windows, não na janela do Python que mostra >>:

Prompt de Comando 
python -m pip install ipeadatapy

O comando pip é do sistema: vai no Prompt de Comando. Código Python, como import, vai na janela do Python. Não misture os dois.

Descobrir o código da série

Os códigos têm nomes técnicos. Para encontrar o certo, filtre a lista por uma palavra do nome:

Python 
import ipeadatapy as ip

todas = ip.list_series()
print(todas[todas['NAME'].str.contains('câmbio', case=False, na=False)].to_string())

Troque 'câmbio' por 'IPCA', 'Selic' ou o que precisar.

Puxar a série e calcular a variação

Salve o trecho abaixo como arquivo .py (no Bloco de Notas, em Salvar como, escolha Todos os arquivos e ponha o nome entre aspas, por exemplo "serie.py") e rode no Prompt de Comando com python serie.py:

Python · serie.py 
import ipeadatapy as ip

def serie(codigo):
    df = ip.timeseries(codigo)
    col = [c for c in df.columns if c.startswith('VALUE')][0]
    return df[['YEAR', 'MONTH', col]].rename(columns={col: 'valor'})

def valor_mes(s, ano, mes):
    linha = s[(s['YEAR'] == ano) & (s['MONTH'] == mes)]
    return float(linha['valor'].iloc[0])

s = serie('BM12_ERV12')
ini = valor_mes(s, 2022, 8)
fim = valor_mes(s, 2026, 3)
print('inicial:', round(ini, 4))
print('final:', round(fim, 4))
print('variacao %:', round((fim / ini - 1) * 100, 2))

Códigos úteis (confirmados em junho/2026)

  • BM12_ERV12 — Taxa de câmbio, R$/US$, comercial, venda, média mensal.
  • PRECOS12_IPCA12 — IPCA geral, número-índice (dez/1993 = 100). Para inflação acumulada entre dois meses: (índice final / índice inicial - 1) × 100.

Dica

Sempre rode como arquivo .py. Colar um bloco grande direto no Prompt ou no >> costuma dar erro de sintaxe, porque cada janela entende uma linguagem diferente.

Alternativa oficial pelo BCB (sem instalar nada além do pandas)

14.2 · BigQuery e SQL — microdados da RAIS (Base dos Dados)

Para contagens precisas por CNAE e município, e séries históricas de estabelecimentos, o caminho é a RAIS tratada pela Base dos Dados, consultada no BigQuery do Google. É o que permite, por exemplo, levantar o número de bancas de jornal de uma cidade ano a ano com fonte primária.

Acesso

Entre em console.cloud.google.com/bigquery logado em uma conta Google. Na primeira vez, crie um projeto (nome qualquer). O modo Sandbox, indicado no topo, é gratuito e não pede cartão, dentro do limite de processamento gratuito.

Tabela

basedosdados.br_me_rais.microdados_estabelecimentos (cobertura de 1985 ao ano mais recente fechado).

Campos-chave para filtrar

  • ano — ano de referência.
  • sigla_uf — UF, por exemplo 'SP'.
  • id_municipio — código IBGE de 7 dígitos. Campinas = '3509502'.
  • cnae_2_subclasse — subclasse CNAE, sem pontuação. Bancas de jornal e revista = '4761002' (CNAE 4761-0/02). Confirme outros códigos no buscador da CNAE (IBGE/Concla).
  • indicador_atividade_ano — use = 1 para contar apenas estabelecimentos ativos no ano.

Consulta de série histórica (exemplo real, bancas em Campinas)

SQL · BigQuery 
SELECT ano, COUNT(*) AS total_estabelecimentos
FROM `basedosdados.br_me_rais.microdados_estabelecimentos`
WHERE sigla_uf = 'SP'
  AND id_municipio = '3509502'
  AND cnae_2_subclasse = '4761002'
  AND indicador_atividade_ano = 1
  AND ano >= 2015
GROUP BY ano
ORDER BY ano
Nota: A RAIS tem defasagem. O ano mais recente costuma ser o anterior ou o retrasado; use ano >= XXXX em vez de fixar o ano de hoje e olhe qual é a última linha que retorna. O número de uma CNAE específica pode divergir de levantamentos de entidades de classe, que às vezes somam subclasses vizinhas (livrarias, papelarias). Ao comparar, confira sempre qual recorte cada fonte usou. Cite na matéria: RAIS/Ministério do Trabalho, CNAE 4761-0/02, município, anos.

14.3 · API de catálogo (CKAN) — descobrir se o dado existe

Boa parte dos portais oficiais brasileiros de dados abertos roda o mesmo software de catálogo, o CKAN. Isso significa que todos respondem no mesmo endereço de API, e que dá para procurar conjuntos de dados por palavra-chave sem navegar página a página. O uso jornalístico é anterior à apuração: antes de protocolar um pedido de LAI (Seção 16.5), vale checar por programa se o dado já está publicado — e, se estiver, em que formato e desde quando.

O endereço

Acrescente /api/3/action/package_search?q=termo à raiz do portal. Não precisa de cadastro nem de chave. O retorno é JSON.

Portais que respondem a esse padrão

  • https://dadosabertos.sp.gov.br — Governo do Estado de SP, inclui a Agemcamp e a Seade.
  • https://www.tesourotransparente.gov.br/ckan — Tesouro Nacional.
  • https://dadosabertos.aneel.gov.br — ANEEL.

Exceção importante: o portal federal dados.gov.br deixou de usar a API padrão do CKAN. Hoje tem API REST própria, documentada em dados.gov.br/swagger-ui, que exige token gerado no painel da organização. O código abaixo não funciona nele.

Script de busca em vários portais

Python · busca_ckan.py 
import requests

def buscar(portal, termo, n=10):
    url = portal + "/api/3/action/package_search"
    r = requests.get(url, params={"q": termo, "rows": n}, timeout=30)
    dados = r.json()["result"]
    print(portal, "—", dados["count"], "conjuntos encontrados")
    for ds in dados["results"]:
        recursos = ds.get("resources", [])
        formatos = sorted({x["format"] for x in recursos if x.get("format")})
        print("  -", ds["title"], "|", ", ".join(formatos))

buscar("https://dadosabertos.aneel.gov.br", "interrupcao")
buscar("https://www.tesourotransparente.gov.br/ckan", "municipios")
Nota: os portais rodam versões diferentes do CKAN e alguns campos mudam de nome entre elas — confira o retorno antes de automatizar. O parâmetro rows limita quantos conjuntos vêm por chamada; para varrer o catálogo inteiro, pagine com start. E lembre que o catálogo informa que o dado existe, não que ele está atualizado: confira a data da última carga no próprio conjunto antes de citar. Cite na matéria: o portal, o nome do conjunto de dados e a data da última atualização informada.

Geração de Infográficos em PNG (Python e matplotlib)

Infográficos gerados a partir dos próprios dados verificados têm uma vantagem sobre os criados manualmente em ferramentas online: o script documenta a fonte, o período e o método de cálculo junto com o gráfico, tornando a verificação reprodutível. A biblioteca matplotlib, padrão em Python, gera PNGs prontos para publicação.

Instalação (uma vez só)

No Prompt de Comando:

Prompt de Comando 
python -m pip install matplotlib

Estrutura básica de um script de infográfico

Salve como arquivo .py e rode com python nome_do_arquivo.py:

Python · infografico.py 
# -*- coding: utf-8 -*-
import matplotlib
matplotlib.use('Agg')           # modo sem janela, gera arquivo direto
import matplotlib.pyplot as plt
from matplotlib import rcParams

rcParams['font.family'] = 'DejaVu Sans'
rcParams['text.parse_math'] = False  # evita que R$ seja lido como fórmula

fig, ax = plt.subplots(figsize=(8, 5))

# dados
categorias = ['Categoria A', 'Categoria B']
valores = [1100, 314]

ax.bar(categorias, valores, color=['#c0392b', '#9aa0a6'])
ax.set_title('Título do infográfico', fontsize=14, weight='bold')
ax.set_ylabel('Variação (%)')

# rótulos nas barras
for i, v in enumerate(valores):
    ax.text(i, v, f'+{v}%', ha='center', va='bottom', fontsize=12, weight='bold')

# nota de rodapé com fonte
ax.text(0.0, -0.16, 'Fonte: IBGE/IPCA e InfoMoney. Período: jan/2002 a mar/2026.',
        transform=ax.transAxes, fontsize=8, color='#555555')

fig.savefig('infografico.png', dpi=200, bbox_inches='tight', facecolor='white')
plt.close(fig)
print('PNG gerado.')

Tipos de gráfico comuns e quando usar

  • ax.bar() — comparações entre categorias (ex.: figurinha vs. inflação).
  • ax.plot() com marker='o' — séries históricas (ex.: bancas por ano).
  • ax.barh() — ranking horizontal (ex.: municípios por índice).
  • ax.pie() — composição percentual (use com parcimônia; evite com mais de cinco fatias).

Boas práticas editoriais para infográficos

  • Sempre incluir fonte e período no rodapé do gráfico, como nota de texto (ax.text com transform=ax.transAxes).
  • Nunca usar parse_math=True quando os textos contêm R$, %, ou letras isoladas: o matplotlib pode interpretar como fórmula e gerar erro ou símbolo errado.
  • Usar dpi=200 ou superior para resolução adequada à publicação impressa ou digital.
  • Cores: evite paletas semafóricas (vermelho/verde) para comparações neutras. Reserve o vermelho para alertar e o azul/cinza para contexto.
  • O título do gráfico deve enunciar a conclusão, não apenas o tema. Correto: "Figurinha dispara acima da inflação (2002 a 2026)". Incorreto: "Comparação de preços".

Atenção ao fluxo de arquivos

  • O script gera os PNGs na mesma pasta de onde é rodado.
  • Para manter o C: limpo, baixe o script do Drive, rode, salve os PNGs onde precisar, e apague o script do C: em seguida. O original permanece no Drive.
  • Scripts de infográfico devem ser guardados no Drive junto com a matéria a que correspondem, para permitir atualização futura dos dados sem reescrever o código.

16.1 · Preço contra inflação (série reprodutível)

Pergunta

Um preço subiu quanto acima ou abaixo da inflação no período?

Exemplo real

O reajuste de 75% no pacote de figurinhas da Copa, confrontado com um IPCA acumulado de 18,89% entre o lançamento do álbum, em setembro de 2022, e o dado mais recente. O aumento superou em quase quatro vezes o custo de vida. O dólar em queda no mesmo intervalo entrou como provocação: se o insumo importado e os royalties ficaram mais baratos, o reajuste reflete margem, e não repasse de custo.

  • Delimite o período: do marco inicial (lançamento, contrato, fato gerador) ao último dado fechado.
  • Puxe o IPCA pela série PRECOS12_IPCA12 (Seção 14.1) ou faça a conta rápida na Calculadora do Cidadão do BCB.
  • Compare a variação do preço observado com a inflação acumulada do período.
  • Quando houver insumo importado ou royalties, cruze com o câmbio (BM12_ERV12) para testar margem contra repasse de custo.
  • Feche com um economista, que valida a leitura, e humanize com fonte de campo (jornaleiro, consumidor).
  • Cite: IPCA/IBGE e período; câmbio do Ipeadata. Ferramentas nas Seções 4, 14 e 15.

16.2 · Contagem por atividade e município (RAIS no BigQuery)

Pergunta

Quantos estabelecimentos de um tipo existem numa cidade, e como esse número evoluiu?

Exemplo real

A série histórica de bancas de jornal em Campinas, levantada na RAIS pela CNAE 4761-0/02. É a contagem que dá lastro a uma reportagem sobre o encolhimento do setor com fonte primária, em vez de número de entidade de classe.

  • Descubra a subclasse CNAE da atividade no buscador da Concla/IBGE.
  • Consulte basedosdados.br_me_rais.microdados_estabelecimentos no BigQuery (passo a passo na Seção 14.2), filtrando por id_municipio, cnae_2_subclasse e indicador_atividade_ano = 1.
  • Lembre da defasagem da RAIS: use ano >= XXXX e veja qual é a última linha que retorna.
  • Ao comparar com números de entidades de classe, confira o recorte: elas às vezes somam subclasses vizinhas.
  • Cite: RAIS/Ministério do Trabalho, código CNAE, município e anos. Repositório na Seção 6.

16.3 · Triangulação de duas séries (verificação por divergência)

Pergunta

O número oficial se sustenta diante de uma série independente que mede a mesma coisa?

Exemplo real

As emissões de gases de efeito estufa de Campinas. O inventário da secretaria municipal apontou queda de 18% e cerca de 3 milhões de toneladas; a série do SEEG, do Observatório do Clima, marcou 2,93 milhões para o mesmo ano. Quando as fontes divergem, a divergência vira pauta.

  • Localize a fonte oficial e uma série independente que meça o mesmo fenômeno.
  • Compare os números e o ano de referência de cada uma.
  • Se divergirem, peça a cada lado que explique o método; a diferença de metodologia costuma ser a história.
  • Apresente as duas, sempre dizendo o recorte de cada uma. Não escolha a que confirma a hipótese.
  • Cite: os dois levantamentos, com órgão, ano e método. Fontes nas Seções 2, 3 e 13.

16.4 · Censo e demografia por recorte territorial (SIDRA)

Pergunta

Qual é o perfil demográfico de um bairro ou cidade que ancora a abertura da reportagem?

Exemplo real

O recorte do Censo 2022 de Campinas extraído do SIDRA, base do painel populacional e dos números de abertura usados em pautas locais.

  • Identifique a tabela no SIDRA (Seção 4) e filtre por município ou setor censitário.
  • Exporte para planilha; para repetir o levantamento, use a API do SIDRA.
  • Anote o número da tabela e o período: é isso que vai na citação.
  • Para o cruzamento estadual, complemente com os painéis da Fundação Seade (Seção 13).
  • Cite: Censo 2022/IBGE, número da tabela SIDRA, recorte territorial.

16.5 · Lei de Acesso à Informação como percurso

Pergunta

O dado não está publicado. Como obtê-lo por via oficial?

Observação de quem responde a pedidos

Um pedido bem delimitado é respondido mais rápido do que um pedido vago. Pedir o documento certo, com período certo, encurta o prazo e fecha a porta para a negativa por pedido genérico.

  • Antes de pedir, confira se o dado já está no Portal da Transparência, no Diário Oficial ou em painel público. Não se pede o que já é público.
  • Escreva o pedido objetivo: cite a LAI, nomeie o documento ou a série e delimite o período.
  • Protocole no e-SIC do ente certo (municipal, estadual ou federal). As três portas estão nas Seções 1, 2 e 3.
  • Se houver negativa ou silêncio no prazo, entre com recurso. Guarde protocolo e datas.
  • Quando for preciso preservar a autoria do pedido, use a via anônima do Queremos Saber (Seção 3).
  • Cite: órgão, número do protocolo e data da resposta.

16.8 · Serviço público e infraestrutura

Pergunta

Por que um problema persiste apesar do investimento anunciado?

Exemplo real

A falta de água em Vinhedo. Reservatórios a 27% da capacidade, chuvas em queda de até 49% em 2024, novos reservatórios entregues, e ainda assim interrupções na região da Capela. A apuração não parte de que a obra falhou; separa o que ela resolveu do que não resolveu.

  • Reúna o dado oficial: níveis, investimento, cobertura, obras entregues.
  • Enquadre sem pressupor fracasso: o que a obra resolveu e o que ainda não resolveu.
  • Ouça o operador como fonte principal e um especialista técnico independente (no caso da seca, um meteorologista) para pesar o fator externo.
  • Feche com o morador afetado, que dá a medida concreta do impacto na rotina.
  • Cite: operador do serviço, série de dados oficiais e período. Fontes nas Seções 2 e 13.

16.9 · Discurso oficial contra o indicador

Pergunta

A narrativa oficial bate com o que os dados mostram?

Exemplo real

O discurso de Campinas como polo de inovação, captado em evento institucional, posto lado a lado com a pressão no custo de vida das periferias. PIB municipal, tarifa do transporte e índice imobiliário sustentam o contraste; a distância entre o discurso e o indicador conduz a matéria.

  • Capture o discurso oficial na fonte: fala em evento, release, peça de campanha.
  • Levante os indicadores duros que testam esse discurso: PIB municipal, custo de vida, tarifa, índice de preços imobiliários.
  • Ponha discurso e indicador lado a lado e deixe a diferença carregar a reportagem.
  • Dê ao poder público o direito de resposta sobre a divergência.
  • Cite: a fonte do discurso e cada indicador, com órgão e período. Fontes nas Seções 1, 4 e 13.

16.10 · Dados de violência: qual número usar?

Pergunta

Quantos casos de violência doméstica um município registra — e por que cada fonte dá um número diferente?

Exemplo real

A apuração da violência doméstica em Campinas (agosto/2026): a estatística mensal da SSP não abre por município, o boletim local (Sisnov) é anual, e o número municipal só saiu da base bruta do SP Vida — cada fonte mede uma coisa diferente e tem um atraso diferente.

  • Antes de tudo, entenda que cada base conta uma coisa diferente: ocorrência (BO registrado na polícia) ≠ notificação (caso atendido na saúde ou assistência) ≠ denúncia (relato a canal como o Ligue 180) ≠ processo (ação na Justiça). Nomeie a fonte de cada número na matéria e nunca compare séries entre bases como se fossem a mesma coisa.
  • A via policial tem um limite verificado na prática: a estatística mensal da Lei Maria da Penha (Seção 2) existe só para Capital, Demacro e Interior — nenhuma via pública da SSP abre essas naturezas por município. A tabela municipal de Dados Mensais traz totais gerais (todas as vítimas, sem vínculo doméstico) e não inclui ameaça, violência psicológica nem descumprimento de medida. Para o dado municipal exato dessas naturezas, o caminho é pedido de LAI à SSP — ou a assessoria de imprensa, que responde recortes em dias.
  • A exceção municipal é o SP Vida (Seção 2): base bruta de crimes contra a vida, registro por vítima, com marcador de violência contra a mulher e tipificação de feminicídio, por município, de 2023 em diante. Escopo restrito: cobre feminicídio e tentativas, não o grosso da violência doméstica.
  • Cuidado com as unidades: a série da Lei Maria da Penha conta vítimas e as tabelas municipais contam ocorrências — os números não podem ser somados nem subtraídos entre si.
  • Para o perfil das vítimas e dos agressores, use a via da saúde: no TabNet do DataSUS (Seção 3), o caminho é Epidemiológicas e Morbidade → Violência interpessoal/autoprovocada (VIVA/Sinan), filtrando o município de residência. Em Campinas, é a mesma base que alimenta o Sisnov — só que tabulável por tipo de violência, sexo, faixa etária e vínculo com o autor. A consolidação nacional leva de um a dois anos. (O TabWin, versão de mesa do programa, só é necessário para microdados brutos do FTP do DataSUS.)
  • Para a camada da denúncia, que capta casos que não viram BO nem notificação, use o Painel da ONDH (Seção 3), com filtro por município e atualização semanal.
  • Para a resposta do Estado, o Painel da Violência Doméstica do CNJ (Seção 3) mostra as medidas protetivas concedidas, negadas e revogadas por município.
  • Os cruzamentos rendem pauta: a distância entre BOs (polícia) e notificações (saúde) mede subnotificação; a razão entre BOs e medidas protetivas mede o funil da proteção.
  • Cite: cada número com sua base, órgão e período — "segundo BOs da SSP", "segundo notificações do Sinan", "segundo denúncias ao Ligue 180".

16.11 · Quem ganhou o contrato, e quem está por trás da empresa

Pergunta

A empresa que venceu a licitação é mesmo independente das concorrentes?

Exemplo real

Uma concessão municipal de transporte coletivo em que o tribunal de contas identificou indícios de que empresas formalmente concorrentes compartilhavam endereços, telefones, estrutura administrativa e vínculos societários, e por isso barrou a homologação do certame. O percurso abaixo refaz, com fontes abertas, o caminho que o tribunal percorreu.

  • Comece pelo edital ou pelo contrato no PNCP (Seção 3): quem venceu, por quanto, com que aditivos e em que datas.
  • Levante o CNPJ de todos os participantes, não só do vencedor. É a comparação entre eles que produz o achado.
  • Abra o quadro de sócios de cada um na Receita Federal (Seção 6) e compare endereço, telefone e nomes. Endereço repetido entre concorrentes é o achado mais comum, e o mais fácil de verificar.
  • Na Junta Comercial (Seção 6), busque as alterações societárias e, principalmente, as datas delas. Reorganização societária às vésperas do edital é sinal, não prova.
  • Verifique se o certame já gerou representação no tribunal de contas ou processo na Justiça (Seção 2). Se gerou, o trabalho técnico já feito ali é fonte, e é pública.
  • O que não estiver publicado, peça por LAI, nomeando o documento e o período (percurso 16.5).
  • Cuidado que sustenta a matéria: coincidência de endereço não prova conluio. Ela prova que existe uma pergunta a ser feita, e essa pergunta vai ao órgão contratante e a cada empresa citada, com prazo e direito de resposta registrados.
  • Cite: número do edital ou do contrato no PNCP, CNPJ e data da consulta ao cadastro, número do processo ou da representação.

A régua dos percursos

Quatro constantes valem para todos. Delimite o período antes de comparar qualquer número. Prefira a fonte primária ao número de segunda mão. Quando duas fontes divergem, a divergência é pauta, não erro a esconder. E documente fonte, período e método junto com o resultado, para que a apuração seja reprodutível e citável.

17

Metodologia: Dados Territorializados (GIS + Estatística Oficial)

Quando usar: Use este método sempre que precisar de um indicador (educação, renda, domicílio, demografia, saúde etc.) para um endereço, obra, bairro ou ponto específico, e a fonte estatística oficial só divulgar esse indicador em uma unidade territorial maior (município, distrito) ou não divulgar recorte territorial nenhum.

O problema que este método resolve: censos e pesquisas oficiais quase sempre têm o dado fino que você precisa, mas não o publicam pronto para consulta por endereço. É preciso descobrir a que unidade territorial mínima (setor censitário, zona, distrito) aquele ponto pertence, e só então buscar o indicador para essa unidade nos arquivos brutos.

Mapeie os caminhos disponíveis

Nem toda fonte é acessível do mesmo jeito. Antes de se comprometer com um caminho, teste rapidamente:

  1. API oficial com geocodificação por ponto (o ideal, quando existe): recebe coordenadas, devolve a unidade territorial diretamente. Nem sempre existe ou está acessível a ferramentas automatizadas (robots.txt bloqueia acesso automatizado com frequência).
  2. API de consulta agregada (tipo SIDRA/IBGE): geralmente acessível, mas verifique o nível territorial mínimo disponível antes de assumir que serve — é comum publicarem só até nível de município, mesmo quando o dado fino existe em outro lugar.
  3. Painel interativo público (dashboards tipo Power BI): muitas vezes tem exatamente o recorte fino que falta em outros lugares, mas exige navegação manual; não é consultável por scraping ou API.
  4. Arquivos brutos por unidade territorial mínima: a fonte mais granular e mais confiável, mas a mais trabalhosa. É o caminho descrito abaixo.
  5. Grade estatística (células regulares): quando a área de interesse não coincide com nenhum setor censitário — o entorno de uma obra, um trecho de avenida, uma mancha que atravessa dois bairros —, use a Grade Estatística do IBGE, que distribui o Censo em células de 200 m (urbano) e 1 km (rural) e pode ser somada por qualquer recorte que você desenhar.

Escolha o caminho mais simples que atenda. Só desça para os arquivos brutos se os anteriores não cobrirem o nível de detalhe necessário.

Passo a passo (arquivos brutos + GIS)

1. Coordenadas do local

Obtenha latitude/longitude do endereço, obra ou ponto de interesse.

2. Identifique a unidade territorial mínima (GIS)

Ferramenta recomendada: QGIS (gratuito, código aberto).

  • Carregue o shapefile (ou geojson) da malha territorial mínima disponível para a fonte que você vai usar (setor censitário, zona eleitoral, distrito administrativo etc.).
  • Crie uma camada de ponto a partir de um CSV simples com colunas lon,lat, definindo o SRC como EPSG:4326 (padrão WGS 84, o mesmo de coordenadas de GPS comuns).
  • Use a ferramenta "Identificar Feições" clicando no polígono onde o ponto cai.
  • Anote o código da unidade territorial (ex.: CD_SETOR no caso do IBGE) e quaisquer campos de contexto úteis (distrito, região administrativa, município).
Atenção a pontos próximos de divisa: Se o ponto estiver perto de uma linha de fronteira entre polígonos, teste mais de uma coordenada do mesmo local (ex.: os cantos de um terreno) para confirmar que todas caem na mesma unidade. Se caírem em unidades diferentes, sinalize a ambiguidade em vez de escolher uma arbitrariamente.

3. Cruze o código territorial com os dados temáticos

  • Baixe o arquivo bruto do tema desejado, organizado por unidade territorial (geralmente um CSV ou pacote de CSVs, um por tema: educação, renda, domicílio, etc.).
  • Localize a linha correspondente ao código territorial encontrado no passo 2, por exemplo via Python:
Python 
import csv
with open(caminho, encoding="latin-1") as f:  # confirme a codificação do arquivo
    leitor = csv.DictReader(f, delimiter=";")  # confirme o delimitador
    for linha in leitor:
        if linha["NOME_DA_COLUNA_DE_CODIGO"] == codigo_territorial:
            print(linha)

O nome exato da coluna de código varia por arquivo — sempre confira o cabeçalho antes de filtrar, não assuma que é igual ao nome usado no shapefile.

4. Decodifique as variáveis

Fontes estatísticas oficiais costumam nomear colunas com códigos genéricos (V00644, Q12, etc.) em vez de nomes legíveis. Praticamente sempre existe um dicionário de variáveis (PDF, planilha ou nota metodológica) na mesma fonte de distribuição — localize-o antes de interpretar qualquer coluna. Nunca infira o significado de uma variável só pelo padrão numérico ou pela posição.

5. Checagem de consistência (obrigatória antes de publicar qualquer número)

Sempre que existir uma variável-resumo isolada (ex.: "total de pessoas alfabetizadas"), some as variáveis desagregadas equivalentes (por faixa etária, por exemplo) e compare com ela. As duas somas devem bater. Essa checagem cruzada é o que dá segurança para publicar um número que você mesmo calculou a partir de microdados, em vez de citar uma fonte secundária.

6. Trate corretamente os códigos de sigilo estatístico

Fontes censitárias costumam usar um marcador (como "X") para indicar que uma célula foi suprimida por sigilo estatístico (contagem pequena demais para divulgar sem risco de identificação individual). Isso não é a mesma coisa que zero, e não deve ser somado, ignorado ou tratado como ausência de dado sem essa ressalva.

Limitações a ter em mente

  • Nem todo indicador existe no nível fino desejado. Se, depois de checar todas as fontes disponíveis, um indicador (ex.: renda por setor censitário) simplesmente não é publicado em nenhum arquivo bruto disponível, não force uma aproximação sem deixar isso explícito — é melhor registrar a limitação do que substituir por um proxy sem dizer que é proxy.
  • Arquivos brutos costumam ser grandes (dezenas a centenas de MB). Isso pode inviabilizar processamento em ambientes com restrição de rede ou de tamanho de transferência — nesse caso, o processamento em GIS/Python pode precisar ser feito localmente, fora da ferramenta que está pesquisando.
  • APIs oficiais nem sempre aceitam acesso automatizado. Tenha um plano B (painel manual, arquivo bruto) quando a API mais conveniente estiver bloqueada para scraping.
  • Regiões administrativas e distritos estatísticos nem sempre coincidem. Um mesmo bairro pode pertencer a uma "região" para fins de gestão municipal e a um "distrito" diferente para fins de estatística oficial. Não presuma equivalência entre sistemas de classificação territorial sem verificar.

Resumo e citação

Em uma frase: Transforme um ponto em um código de unidade territorial via GIS, depois transforme esse código em indicador via cruzamento com os microdados oficiais — e sempre confirme com uma soma de conferência antes de publicar.

Cite na matéria: A fonte estatística (ex.: Censo 2022/IBGE, RAIS/Ministério do Trabalho), a unidade territorial mínima usada (ex.: setor censitário, zona eleitoral), o recorte específico (endereço, bairro, obra) e o período. Menção ao método só é necessária se relevante para a história.
